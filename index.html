How it works

1

Create a key

In Garmin Connect on the web, make a Personal API key. It takes two minutes and we show you where to click.

2

Paste it here

Choose what to include and from which date. Your key stays in your browser tab.

3

Download your zip

We fetch everything from Garmin and pack it into one file. Then you delete the key.

What you get

Everything Garmin's Personal API offers:

  • Every activity, with its original FIT file
  • A spreadsheet of all your activities
  • Daily steps, calories, stress and Body Battery
  • Sleep, night by night
  • HRV and heart rate zones
  • Weight and VO2 max
  • Optional: heart rate, SpO2 and sleep detail per day
  • The raw data, untouched, for developers

The spreadsheets open in Excel, Numbers and Google Sheets. The FIT files import into Strava and most training apps.

Your key stays yours

Only in your tab

The key is never saved. Close the tab and it is gone.

Through a small relay

Garmin's servers do not accept requests from websites, so a small relay passes them on. Your key goes through it once to get a 24 hour pass. Nothing is stored or logged.

Open code

The relay is about a hundred lines. Read it on GitHub and check the version shown at the bottom of every page.

Use a key that expires in 30 days and delete it when you are done. Then even the relay has seen nothing that still works.

Prefer to run it yourself?

Your own copy means your key only touches computers you control.

On your computer

Needs Node.js. Then open the address it prints.

git clone <repository>
cd garmin-data-takeout
npm install
npm run dev

Your own copy online

Deploy the repository to your own free Cloudflare account with npm run deploy.

Just the code

Questions

Is it free?Yes. No account, no ads, no tracking.

Is this made by Garmin?No. It uses the Personal API that Garmin offers to every user.

Can I close the tab?Better not, but if you do, start again with the same choices and it continues where it stopped.

How long does it take?Garmin allows about one request per second. Several years of data take a few minutes.

Why not Garmin's own export?You can use that too. It arrives by email after a few days; this is right away and you choose what to include.
